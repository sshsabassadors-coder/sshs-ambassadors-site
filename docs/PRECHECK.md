# 사전 결정 기록

작성일: 2026-08-19 (Asia/Seoul)

## 확정된 운영 결정

- UI는 한국어·영어 전환형이다.
- 슬로건은 기존 홍보단 HTML의 `Connecting SSHS to the World: The Voice of Korea’s Young Scientists`를 사용한다.
- Intro, Tour, 게시된 Survey와 익명 응답은 공개한다.
- `member`는 Survey 결과와 Data Archive를 열람하고 Archive 파일을 사이트에서 업로드한다.
- `admin`은 member 권한에 더해 Tour·Survey·Archive를 생성·수정·게시·숨김·삭제한다.
- 공개 회원가입은 제공하지 않고 관리자가 계정을 생성하거나 초대한다.
- 새 Supabase 프로젝트를 사용하며 기존 HTML의 Supabase/Firebase 설정은 복사하지 않는다.
- Data Archive에는 개인정보를 올리지 않으며 기존 면접 평가 자료는 완전히 제외한다.
- 두 PPT는 초기 게시하지 않는다. 승인·정리된 파일을 사용자가 나중에 Archive에서 추가한다.
- GitHub 저장소는 가장 단순한 공개 저장소 + GitHub Pages + custom domain 없음 기준으로 문서화한다.

## 확정된 지도 원칙

- 새 지도는 방문객용 개략도다. 정확한 건축 평면도나 인터넷 캠퍼스 이미지를 재사용하지 않는다.
- 사용자가 제공한 예시처럼 흰색·옅은 회색 아이소메트릭 층 블록과 분홍색 경로를 사용한다.
- 현재 층만 푸른색으로 강조하고 나머지는 낮은 대비로 표시한다.
- 출입 통제·보안 설비·비상 동선은 표시하지 않는다.
- 대회의실은 시작과 종료에 같은 슬라이드를 재사용하는 순환 경로다.
- 풍동실·창작실은 지도에서 위치 개념을 유지하되 하나의 설명 정류장으로 묶는다.
- 물리과·생물과·지구과학과·화학과·정보과는 교과 공간과 실험실을 구분하지 않는 설명 단위다.
- 천문대는 `예지관 옥상 / Rooftop`으로 표기한다.
- 창의인재관은 공식 영문 브로슈어 기준으로 1층 정보과, 2층 화학과다. 3층 화학 공간은 투어에서 방문하지 않는다.

## 구현 중 합리적으로 정한 값

- Tour 이미지: JPEG/PNG/WebP, 최대 10MB
- Archive 파일: PDF/PPTX/DOCX/XLSX, 최대 25MB
- ZIP/HTML/SVG/실행 파일은 업로드 대상에서 제외
- 실제 Supabase가 연결되기 전 배포본은 개인정보 없는 역할별 미리보기 데이터를 사용
