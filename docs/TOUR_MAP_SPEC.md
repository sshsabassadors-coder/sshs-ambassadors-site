## 구조 메모

- 모든 건물은 같은 얕은 탑뷰 투영과 18단위 돌출 깊이를 사용한다. 건물별 전면 원근을 따로 적용하지 않는다.
- 역사관은 정문 기준 예지관 1층 왼쪽, 대회의실은 같은 층 오른쪽에 둔다.
- 예지관 중앙 대계단은 예지관 1층부터 옥상까지 연결한다.
- 중앙 대계단 경로는 꾸불꾸불한 계단 무늬를 따라가지 않고 지도에서 한 번의 직선 상승으로 표현한다.
- 예지관 2층과 융합인재관 2층 이룸관은 가교로 연결한다.
- 도서관에서 음악실로 내려가는 동선은 가교가 아니라 융합인재관 내부 계단이다.
- 음악실이 있는 융합인재관을 완전히 나온 뒤, 창의인재관 2·3층 사이 계단참으로 이어지는 실외 연결 통로를 이용한다.
- 화학과와 정보과는 창의인재관 1–3층 대계단으로 연결된다.
- 동아리실, 세미나실, 체육관은 이번 투어 정류장에서 제외한다.
- 정보과에서 예지관으로 돌아오는 길은 위 연결 통로보다 아래에 있는 계단·통로다.
- 융합인재관의 엘리베이터와 화장실, 예지관 계단 옆 화장실, 창의인재관의 반복 시설은 방향 파악용으로만 취급하고 Tour 정류장으로 만들지 않는다.
- 우암관은 전체 맥락에만 존재하며 투어 정류장이 아니다. `우암관 1층 ≈ 예지관 2.5층`, `예지관 1층 ≈ 창의인재관 2.5층`은 높이 참고일 뿐, 확인되지 않은 연결을 만들지 않는다.

## 현재 SVG의 한계

손그림을 건축 도면으로 해석하지 않았기 때문에 방별 외곽, 계단의 실제 길이, 통로 각도는 개략적이다. Intro는 전체 지도를, Tour는 해당 구역의 확대 viewBox를 사용한다. 이동 완료 구간은 연한 분홍, 마지막 이동 구간은 진한 분홍으로 구분한다. 사용자가 실제 투어 중 발견한 차이는 `tourStops` 데이터의 좌표와 SVG 건물 footprint를 수정해 반영할 수 있다.
