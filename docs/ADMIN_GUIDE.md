# 관리자·부원 사용 가이드

## 역할 요약

- `member`: Survey 결과 열람, Data Archive 열람·파일 업로드, Tour 장소 설명 초안 추가
- `admin`: member 기능 + Tour·Survey·Archive 전체 관리

공개 사용자는 로그인 없이 Intro, Tour, 게시된 Survey 응답만 이용한다.

## 1. 로그인

1. 우측 상단 `로그인`을 누른다.
2. 관리자가 초대한 이메일과 비밀번호를 입력한다.
3. 로그인 뒤 원래 접근하려던 화면으로 이동한다.
4. 비밀번호를 잊었으면 이메일을 입력한 뒤 `비밀번호 재설정`을 누른다.

Supabase 환경 변수가 없는 개발 배포에서는 개인정보 없는 `Member로 미리보기`, `Admin으로 미리보기`가 보인다. 실제 프로젝트가 연결되면 자동으로 숨겨진다.

## 2. Tour 관리 (admin)

`Admin → Tour`에서 정류장 11개를 관리한다.

- 순서: 같은 순환 경로 안에서 정류장 순서를 정한다.
- 이름: 한글·영문을 모두 입력한다.
- 건물·층: visitor badge에 표시된다.
- 설명: 한글·영문 설명과 route note를 입력한다.
- 사진: JPG/PNG/WebP, 10MB 이하, 대체 텍스트 필수
- 게시: 비공개 상태에서 미리 확인한 뒤 게시한다.

SVG 건물 외곽과 통로 도형 자체는 코드 자산이다. 정류장 순서·설명·사진은 데이터로 바꿀 수 있지만, 실제 연결 통로가 달라질 때는 `CampusMap.tsx`와 `TOUR_MAP_SPEC.md`를 함께 수정한다.

각 Tour 장소의 `MEMBER NOTES → 설명 추가`에서 부원이 한글 설명과 선택 영문 설명을 초안으로 남길 수 있다. 초안은 로그인한 부원끼리 검토하고, admin이 사실·개인정보·한영 표현을 확인한 뒤 게시하거나 삭제한다. 기존 공식 설명을 직접 덮어쓰지 않고 별도 초안으로 저장된다.

## 3. Survey 관리 (admin)

`Admin → Survey`에서 설문을 만들고 게시 상태를 바꾼다.

지원 문항:

- 짧은 글, 긴 글
- 단일 선택, 복수 선택
- 1–5 척도
- 예/아니요

조건부 문항은 `특정 question_key의 값이 X일 때 표시` 방식이다. 조건이 걸린 필수 문항은 화면에 보일 때만 필수로 검증된다.

상태:

- `draft`: 공개 목록에 보이지 않음
- `published`: 공개 목록과 익명 응답 허용
- `closed`: 목록은 보이지만 새 응답 차단

`Result`에서는 응답 수, 평균, 분포, 자유 의견, 원시 응답표를 확인하고 CSV를 내려받는다. 이름·학번·이메일 문항을 추가하지 않는다.

## 4. Archive 사용 (member/admin)

### member 업로드

1. `Data Archive → 자료 업로드`를 누른다.
2. PDF/PPTX/DOCX/XLSX 중 하나를 고른다.
3. 파일당 25MB 이하인지 확인한다.
4. 업로드가 100%가 될 때까지 창을 닫지 않는다.

member는 새 파일을 올릴 수 있지만 기존 컬렉션·기록·파일을 수정하거나 삭제할 수 없다. 잘못 올린 파일은 admin에게 삭제를 요청한다.

### admin 편집

`Admin → Archive`에서 다음을 관리한다.

- 컬렉션 제목·요약·대표 이미지·순서·게시 상태
- 기록 날짜·연도·제목·부제·본문 블록·순서·게시 상태
- 제목, 문단, 강조, 이미지, 갤러리, 첨부, 링크, 구분선 블록
- 업로드 파일의 연결 기록과 표시 이름

본문에 HTML을 붙여 넣지 않는다. 외부 링크는 `https://` 주소만 사용하고 게시 전 직접 확인한다.

## 5. 게시 전 체크

- 한글과 영문이 모두 채워졌는가?
- 학생 이름·학번·연락처·평가 내용이 없는가?
- 사진에 나온 사람의 공개 사용 승인이 있는가?
- QR 코드와 지난 모집 마감일이 남아 있지 않은가?
- Archive 파일이 허용 형식·용량인가?
- Tour를 아래로 스크롤할 때 장소 순서와 실제 이동이 일치하는가?
- 공개 상태를 바꾸기 전에 미리보기로 확인했는가?

## 6. 운영 권장 순서

1. admin이 Tour·Survey·Archive 구조를 만든다.
2. `draft` 상태에서 member 1명이 검토한다.
3. 한영 문구와 파일을 확인한다.
4. 게시한다.
5. 방문 후 Survey 결과와 Tour 회고를 Archive에 남긴다.
