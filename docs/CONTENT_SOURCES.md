# 콘텐츠 근거와 사용 범위

확인일: 2026-08-19

## 1. 학교 공식 영문 브로슈어

- 파일: `서울과학고 2025 홍보 브로슈어(영문).pdf`
- 표지 표기: Seoul Science High School, April 2025
- 프로젝트 저장소에는 원본 PDF를 복사하지 않음
- 사용한 사실:
  - 1989년 개교
  - 2009년 영재학교 전환
  - 2025년 2월 기준 총 4,836명 졸업
  - Learner Profile: Collaboration, Creativity, Challenge
  - 천문대·풍동·창작 장비·각 과학 교과 공간의 일반적 용도
  - Campus Guide 건물 영문명
- 수치는 항상 `2025년 기준`으로 표시한다. 최신 수치처럼 표현하지 않는다.

## 2. 학교 공식 웹사이트

- URL: [서울과학고등학교 공식 홈페이지](https://sshs.sen.hs.kr/)
- 검색 확인일: 2026-08-19
- 현재 자동 확인 환경에서는 학교 웹 보안 필터 화면이 표시되어 세부 본문을 사실 근거로 사용하지 않았다.

## 3. 사용자 제공 지도·확인 답변

- 손그림 4장: 1층, 2·3층, 4·5층, 창의인재관
- 추가 예시 사진: 2025 Korean Air Leaders Forum 아이소메트릭 안내도
- 사용 범위: 건물 상대 배치, 층 겹침, 계단·가교 연결, 원하는 지도 표현 방식
- 최종 SVG는 새로 제작했으며 원본 이미지 픽셀이나 고유 도형을 복사하지 않았다.

## 4. 로고

- 파일: 사용자 제공 `logo(2).png`
- 사용 승인: 사용자 확인 완료

## 5. 의도적으로 사용하지 않은 자료

- 인터넷 캠퍼스 지도: 배치 이해에만 사용, 최종 사이트에 재게시하지 않음
- 영문 브로슈어의 사진: 재호스팅하지 않음
- 두 PPT: 초기 Archive에서 제외
- 기존 HTML의 DB 키·Firebase 설정: 완전히 제외
- 면접 평가 엑셀·ZIP과 개인 평가 내용: 열람·복사·요약·게시 대상에서 완전히 제외
